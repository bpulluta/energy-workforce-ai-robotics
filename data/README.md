# Data Folder

This folder contains the publication dataset and its codebook.

## Files

- `hydropower_rai_matches_full.csv`: full match table used in the hydropower RAI workforce analysis.
- `DATA_DICTIONARY_all.md`: detailed data dictionary for all fields in the CSV.
- `CHECKSUMS.sha256`: SHA-256 hashes for the data files in this folder.

## Notes

- The CSV is the primary data file for the publication.
- The data dictionary is the authoritative source for column meaning, codes, and missing-value conventions.
- Use the checksum file to confirm the archive integrity after cloning or downloading.
